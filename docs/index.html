Bridge

A post-compile Maven plugin and supporting bytecode library that adds bytecode-level language features using existing Java semantics.

SupraCraft-maintained fork. This repository is derived from ME1312/Bridge. Upstream authorship and license history are preserved; new SupraCraft artifacts use SupraCraft-owned coordinates and provenance.

Where to consume Bridge

GitHub Packages is the canonical repository for current immutable Bridge publications. It requires authentication. Release workflows may also publish an anonymous static Maven mirror under /Bridge/maven/; that mirror contains release material, not the rolling development package set.

Project contract

Builds use the Maven Wrapper, emit Java 21 bytecode, generate SBOM/provenance evidence, and publish the exact bytes already built and tested. See the machine-readable project contract and README for the current operational details.
