What Bridge is

Bridge provides post-compile Maven transformations plus runtime/API and ASM helper modules. New publications use the SupraCraft Maven group io.github.supracraft.bridge. Bridge is derived from ME1312/Bridge; upstream authorship and license history are preserved.
